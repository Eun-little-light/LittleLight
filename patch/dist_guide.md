# Little Light {VER} — 사용 안내

Danbooru 태그 기반 **일반 일러스트(SFW)** 생성 도구입니다. ComfyUI와 연동되는 Windows 단일 실행 파일입니다.
화면은 한국어로 보이고 실제 프롬프트는 영문 Danbooru 태그로 들어갑니다. 부정 프롬프트에는 항상 `nsfw, nude`가 들어갑니다.
설치·준비물(모델 · 커스텀 노드 다운로드 링크 포함)은 같은 폴더의 **필요한 것.txt**를 보세요.

## 실행
- **`Little Light.exe`를 더블클릭** → 전용 창으로 열림 (브라우저 필요 없음, 프로그램은 이 exe 하나 — 처음 켤 때 숨김 폴더 `.engine`에 본체를 풀어 둠). 내부 주소 `http://127.0.0.1:7866`
- ComfyUI가 꺼져 있으면 먼저 켭니다. 창을 닫으면 앱도 꺼집니다. 창 크기·위치는 기억하고, 창을 줄여도 버튼 글자가 꺾이거나 넘치지 않게 화면이 맞춰집니다. 앱 화면을 열면 참고 그림·워크플로를 ComfyUI에 맞춰 자동 설정하고, 모델 파일 이름이 달라도(Civitai 원래 이름 · .pth 등) 워크플로를 맞춥니다.

## 화면 구성
- **생성 탭**: 프롬프트 편집, 워크플로·크기·시드, 생성, 결과
  - **태그 선택기**: 장면(1인 · 2인 · 5인), 동작, 감정, 복장, 머리 장식, 구도, 조명, 화풍·분위기, 이펙트, 계절·날씨, 소품, 배경, 작가 화풍, 푸른 밤
  - **기본 캐릭터 ▾**: 캐릭터 프롬프트를 불러옴. 옆의 **✎ 캐릭터**로 이름 지정 · 내 캐릭터 추가
  - **가슴 크기 (필수)**: 작게 / 보통 / 크게 / 아주 크게 — 모든 생성에 적용
- **연작 탭**: 장면 + 테마(하루 일과 · 사계절 · 시간대 · 날씨 · 감정 · 카메라 앵글 · 액션)를 고르면 장면마다 한 장씩 자동 생성
  - 복장 · 배경 · 부위별 복장 · **화풍(견본 썸네일)** · 연출·효과를 타일로 고름
  - 진행도 표시, 중단하거나 앱을 껐다 켜도 "이어서 생성"
- **편집 탭**: 그림의 배경을 지워 투명 PNG(누끼)로 — 파일 열기 · 끌어다 놓기 · 최근 생성 그림 · 그림 상세 창의 '✂ 누끼 따기'로 가져와 '배경 제거'. 가장자리 정리 · 부드럽게 · 여백 자르기 · 배경색 고른 뒤 다운로드 (ComfyUI `models\background_removal\birefnet.safetensors` 필요)
  - 누끼 권장 값: **가장자리 정리 0~10 · 부드럽게 1px** (가는 머리카락 유지). 배경 잔티·흐린 테두리가 남으면 정리 **15~25**, 30 이상은 머리카락 끝이 사라짐, 부드럽게 2px 이상은 테두리가 흐려짐
- **프롬프트 자동 정리** (설정 탭, 기본 켜짐): 생성 직전에 중복 태그를 지우고 인원 → 핵심 체위 → 캐릭터 외모 → 동작 → 복장 → 표정 → 배경 → 연출 → 품질 순으로 정렬. 뒤로 밀려 잘 안 먹던 외모·체위가 잘 나옵니다.
- **남자 얼굴 숨기기 보강**: '남자 얼굴 숨기기'가 켜져 있으면 `faceless male`을 인원 태그 바로 뒤에 가중치 1.3으로 넣고, 부정 `male face`도 1.3으로 — 남자 얼굴이 덜 그려집니다.
- **빠른 모드** (기본 켜짐, 설정 탭 · 생성 버튼 위에서 끄고 켬): 그림체를 정하는 기본 생성은 그대로 두고 얼굴 보정 · 업스케일 단계만 줄여 한 장당 약 25% 빨라집니다 (그림은 거의 같고, 얼굴 표정이 살짝 다를 수 있음).
- **생성 우선순위**: 생성 버튼 위 '대기열' 줄 → **대기열 보기 · 순서 바꾸기**에서 작업마다 맨 앞으로 · 맨 뒤로 · 취소(실행 중은 중단). '새 생성은 맨 앞으로'를 켜면 새 생성이 맨 앞에 들어감 (누끼는 항상 맨 앞)
- **갤러리 · 태그 추출 · 워크플로 · 설정** 탭

## 주요 기능
- **화풍**
  - 파스텔 홀로그램: 흰 배경 · 파스텔 · 무지갯빛 · 흩날리는 머리 · 반투명 날개 (참고 그림 화풍 판 있음)
  - 작가 화풍: 픽시브 인기 작가 100명(Danbooru 태그가 있는 작가) — 버튼마다 견본 썸네일
  - 푸른 밤: 푸른 단색조 · 역광 · 메이드 (참고 그림 화풍 판 있음, 옷은 무광)
  - 화풍을 고르면 그 화풍에 맞는 워크플로로 자동 전환됩니다.
- **캐릭터**
  - 기본 캐릭터 6명(외모 설명으로 표시) — 이름은 직접 붙임
  - 내 캐릭터: 이름 · 설명 · 외모 태그(항상 유지) · 의상 태그(연작에서 복장을 고르면 교체) · 인식 태그 · 마녀 화풍 유지
  - 캐릭터별 폴더 저장: 프롬프트의 머리·눈 태그로 캐릭터를 알아보고 `ComfyUI output\LittleLight\<캐릭터>`에 저장 (설정 탭에서 켜고 끔)
- **다시 생성**: 생성 결과 아래와 그림 상세 창의 `↻ 다시 생성`(새 시드) · `↻ 다시 생성 + 이 그림 기록 삭제`, 연작 결과 칸의 `↻`
- **내 태그**: 직접 만든 태그 그룹(효과·연출 / 복장 / 배경)을 태그 선택기와 연작에 추가

## 업데이트
- `Little Light.exe`를 켤 때 GitHub에서 새 버전을 확인하고, 있으면 물어본 뒤 바꿔서 실행합니다. 데이터(프리셋 · 기록 · 설정 · 내 캐릭터)는 그대로입니다.
- 앱 화면에도 새 버전 안내가 뜨고, 설정 탭 '업데이트 확인'으로 직접 확인할 수 있습니다.
